## Отчет по лабораторной работе "Создание первого Telegram-бота без программирования"  

### Описание задачи  
Для работы выбрала вариант - "Бот-ассистент для задач", это актуально для меня в повседневной жизни и для работы  
**Бот должен:**  
  - Принимать задачи в текстовом виде  
  - Организовывать их по приоритетам  
  - Отправлять напоминания  
  - Формировать списки дел  

### Промпт для LLM  
С помощью @BotFather в Телеграм создала своего бота и сохранила токен.  
Составила **первичный промпт**:  
>Создай Telegram-бота на Python с использованием библиотеки python-telegram-bot.  
>
>* Принимать задачи в текстовом виде  
>* Организовывать их по приоритетам  
>* Отправлять напоминания  
>* Формировать списки дел  
>
>Функционал бота:  
>- Что должен делать бот:  
>Принимать задачи в текстовом виде от пользователя  
>Организовывать задачи по приоритетам (например: высокий, средний, низкий)  
>Отправлять напоминания о задачах (по времени и по дате)  
>Формировать списки дел и показывать их пользователю по запросу  
>Позволять отмечать задачи как выполненные  
>Поддерживать удаление и редактирование задач  
>
>- Какие команды должны быть:  
>Добавить новую задачу  
>Показать все текущие задачи  
>Отметить задачу как выполненную  
>Удалить задачу  
>Изменить приоритет задачи  
>Показать все команды  
>
>- Как бот должен отвечать:  
>Подтверждать добавление задачи: «Задача добавлена!»  
>Выдавать список задач с номерами, приоритетом и статусом  
>Подтверждать выполнение или удаление: «Задача выполнена!» / «Задача удалена!»  
>Отправлять уведомления о задачах с истекающим сроком  
>
>- Какие данные хранить:  
>Текст задачи  
>Дата и время создания  
>Статус задачи (выполнена / не выполнена)  
>Приоритет задачи (высокий / средний / низкий)  
>Дата и время напоминания (если требуется)  
>
>Требования:  
>- Бот должен быть простым и понятным  
>- Код должен быть хорошо прокомментирован  
>- Использовать файл для хранения данных (JSON или SQLite)  
>- Добавить обработку ошибок  
>
>Создай:  
>1. Файл bot.py с кодом бота  
>2. Файл requirements.txt с зависимостями  
>3. Файл README.md с инструкцией по запуску  
>4. Файл .env.example для примера конфигурации"
