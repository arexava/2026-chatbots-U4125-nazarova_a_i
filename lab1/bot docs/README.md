# Telegram-бот «Список дел»

Простой бот на Python (`python-telegram-bot`) для задач с приоритетами, напоминаниями и хранением в JSON.

## Возможности

- Добавление задач текстом с выбором приоритета (высокий / средний / низкий)
- Просмотр списка с номерами, приоритетом и статусом
- Отметка выполнения, удаление, смена приоритета
- Напоминания по дате и времени (уведомление в чат)
- Данные сохраняются в файл (JSON)

## Требования

- Python 3.10+
- Токен бота от [@BotFather](https://t.me/BotFather)

## Установка

```bash
cd "путь/к/lab1"
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Скопируйте пример конфигурации:

   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и укажите `TELEGRAM_BOT_TOKEN`.

## Запуск

```bash
source .venv/bin/activate
python bot.py
```

Остановка: `Ctrl+C` в терминале.

## Команды

| Команда | Описание |
|--------|----------|
| `/start` | Приветствие и краткая справка |
| `/help` | Все команды |
| `/add` | Добавить задачу (см. формат ниже) |
| `/list` | Показать все текущие задачи |
| `/done` | Отметить задачу выполненной |
| `/delete` | Удалить задачу |
| `/priority` | Изменить приоритет задачи |
| `/reminder` | Задать или снять напоминание |

### Формат `/add`

```
/add [высокий|средний|низкий] текст задачи
```

Если приоритет не указан, используется **средний**.

Примеры:

```
/add Купить хлеб
/add высокий Сдать отчёт до пятницы
```

### Напоминание

```
/reminder <номер> ДД.ММ.ГГГГ ЧЧ:ММ
/reminder <номер> off
```

Пример: `/reminder 3 15.04.2026 09:00`

## Файл данных

По умолчанию создаётся `tasks.json` в каталоге запуска. Путь можно задать переменной `TASKS_FILE` в `.env`.

## Устранение неполадок

- **Бот не отвечает** — проверьте токен и что процесс `bot.py` запущен.
- **Ошибка при установке** — используйте актуальный Python и виртуальное окружение.
- **Напоминания не приходят** — убедитесь, что бот запущен в момент наступления времени; проверьте часовой пояс (используется локальное время сервера/компьютера).
