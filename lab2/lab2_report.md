## Отчет по лабораторной работе "Подключение бота к данным"  
**Цель:** Научиться подключать бота к внешним источникам данных и работать с ними через LLM-генерацию кода.  

### Описание интеграции 
Выбранный источник данных - подключение к API (Новости).Почему такой выбор - хотелось освоить механику интеграции бота с публичным API.  
Перешла на сайт, указанный в описании лабораторной, зарегистрировалась и получила персональный ключ.  

### Промпт для LLM  

Исходный промпт:    
```bash
Улучши моего Telegram-бота, добавив интеграцию с API новостей (NewsAPI).  

Текущий функционал бота:  
- /add [приоритет] текст — добавить задачу  
- /list — показать список задач  
- /done номер — отметить задачу выполненной  
- /delete номер — удалить задачу  
- /priority номер приоритет — изменить приоритет  
- /reminder номер дата время — установить напоминание  
- /help — список команд  

Бот уже умеет работать с задачами и хранит их в JSON.  

Новый функционал:  
- Получение новостей через NewsAPI  
- Возможность запрашивать новости по ключевому слову  
- Отображение списка новостей (заголовок + ссылка)  
- Обработка ошибок (если API не отвечает или нет новостей)  

Какие команды добавить:  
/news — показать последние новости  
/news <тема> — показать новости по теме (например: /news technology)  
/news_today — топ новостей за сегодня  

Данные:  
Использовать API https://newsapi.org  
Пример запроса:  
https://newsapi.org/v2/top-headlines?country=us&apiKey=YOUR_API_KEY  

Требования:  
- Код должен быть простым и понятным  
- Добавить обработку ошибок  
- Хорошие комментарии  
- Использовать библиотеку requests для API  
- Сохранить существующий функционал бота  
- Не ломать текущие команды  

Создай:  
1. Обновленный bot.py  
2. Обновленный requirements.txt (если нужна requests)  
3. Обновленный README.md с описанием новых команд  
```  
Внесла мой API ключ в файл .env и запустила бота. Новые команды отобразились и запустились, показали список новостей.
